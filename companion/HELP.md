# Wyrestorm Matrix

This module will control a WyreStorm MX-0808-H2A-MK2 8×8 HDMI matrix switcher.

## Configuration

- IP Address
- Enable Verbose Logging

## Actions

- Select Input
- Select Output
- Route Input to Output

## Feedbacks

- Selected Input is Routed to Selected Output

## Variables

- Output [number] Current Input
